# 03 Intermediate: Adding Tools to an Agent

In this tutorial, we'll explore how to equip your `deepagent` with tools, significantly expanding its capabilities. Tools allow an agent to interact with its environment, whether that's searching the internet, reading files, or calling external APIs.

## The `tools` Argument

The primary way to add tools to a `deepagent` is through the `tools` argument in the `create_deep_agent` function. This argument accepts a list of tool functions that your agent can call.

As documented in the knowledge base, here's how you can provide a custom `internet_search` tool to your agent:

```python
import os
from typing import Literal
from tavily import TavilyClient
from deepagents import create_deep_agent

# Make sure to set your TAVILY_API_KEY environment variable
tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])

def internet_search(
    query: str,
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
    include_raw_content: bool = False,
):
    """Run a web search"""
    return tavily_client.search(
        query,
        max_results=max_results,
        include_raw_content=include_raw_content,
        topic=topic,
    )

agent = create_deep_agent(
    tools=[internet_search]
)
```

In this example, the `internet_search` function is now available for the agent to use whenever it needs to perform a web search to answer a question.

## Built-in Tools

`deepagent` comes with a powerful set of built-in tools provided by middleware, so you don't have to build them from scratch. One of the default middlewares is the `FilesystemMiddleware`, which gives the agent the ability to:

*   List files (`ls`)
*   Read files (`read_file`)
*   Write files (`write_file`)
*   Edit files (`edit_file`)
*   Find files with glob patterns (`glob`)

This means that even without explicitly passing any tools, your agent has access to a file system.
