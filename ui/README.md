# DeepAgent Analytics Dashboard

A modern web interface built with Next.js and React for browsing, editing, and interacting with the educational content generated by the DeepAgent autonomous analysis pipeline.

## Features

- **Project Library**: Visual overview of all analyzed codebases and their processing status.
- **Interactive Tutorial Viewer**: Markdown-based reader with syntax highlighting and integrated diagrams.
- **Hierarchical Curriculum**: Navigational sidebar that groups lessons by complexity (Beginner, Intermediate, Advanced).
- **Filesystem Synced**: Directly reads and writes to the `data/` directory, ensuring it stays in sync with the CLI pipelines.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS / Vanilla CSS
- **Components**: Radix UI / Lucide React
- **Runtime**: Node.js 20+

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Access the dashboard:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Data Integration

The UI expects the analysis results to be located in the parent directory's `data/` folder. It specifically looks for:
- `data/knowledge_base/`: Summaries and module descriptions.
- `data/tutorials/`: Generated educational markdown files.
- `data/bench/`: Benchmark and evaluation logs.

## Development

- `app/`: Contains the main page routes and layout.
- `components/`: Modular UI components (Navigation, Card, Content Viewer).
- `lib/`: Helper functions for filesystem access and markdown parsing.
