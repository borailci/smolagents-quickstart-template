# Citations and Fact-Checking with Instructor

## 1. Goal
In this tutorial, you will learn how to use `instructor`'s `CitationMixin` to ensure that the outputs of your language model are grounded in provided context. By the end, you will be able to add fact-checking capabilities to your Pydantic models, making your LLM applications more reliable and trustworthy.

## 2. Prerequisites
- Python 3.9+
- Basic understanding of Pydantic and Language Models.
- `instructor` library installed (`pip install instructor openai pydantic regex`)

## 3. Architecture
The `CitationMixin` works by allowing you to provide a `validation_context` to `instructor`'s `create` method. This context is then used to verify that the `substring_quotes` generated by the LLM actually exist within the provided text, ensuring factual grounding.

```mermaid

    A["User Prompt (with context)"] --> B["LLM (e.g., OpenAI GPT)"]
    B --> C["Instructor (patching client.chat.completions.create)"]
    C --> D["Pydantic Model (with CitationMixin)"]
    D --> E["`validation_context` for fact-checking"]
    E --> F["Extracted Data (with verified citations)"]
```

## 4. Step 1: Define Your Pydantic Model with `CitationMixin`
First, we need to create a Pydantic model that inherits from `CitationMixin`. This mixin adds a `substring_quotes` field to your model, which will store the verified citations. It also provides the validation logic to check these quotes against the context.

Create a file named `citation_example.py`:

```python
from pydantic import BaseModel, Field
from instructor.dsl import CitationMixin

class UserInformation(CitationMixin, BaseModel):
    name: str = Field(description="The name of the person")
    age: int = Field(description="The age of the person")
    occupation: str = Field(description="The occupation of the person")
    
    class Config:
        arbitrary_types_allowed = True

```

- We import `CitationMixin` from `instructor.dsl`. This mixin automatically adds the `substring_quotes` field and the necessary validation logic to our model.
- We define `UserInformation` as a standard Pydantic model with fields like `name`, `age`, and `occupation`.
- The `Config` class with `arbitrary_types_allowed = True` is included to prevent potential Pydantic validation errors with certain Instructor internal types (though it might not be strictly necessary for all versions).

## 5. Step 2: Extract Information with Fact-Checking
Now, let's use our `UserInformation` model with `instructor` to extract data from a text while also fact-checking the extracted quotes.

Add the following to `citation_example.py`:

```python
import openai
import instructor

# Patch the OpenAI client
client = instructor.patch(openai.OpenAI())

# Our context for fact-checking
context = (
    "Betty was a student. Jason Liu is a software engineer. "
    "Jason is 30 years old and lives in San Francisco."
)

# Call the LLM to extract information
user_info: UserInformation = client.chat.completions.create(
    model="gpt-4o-mini",
    response_model=UserInformation,
    messages=[
        {
            "role": "user",
            "content": f"Extract information about Jason from the following text: {context}",
        }
    ],
    validation_context={"context": context},
)

print(user_info.model_dump_json(indent=2))

# Verify that the quotes are actually in the context
for quote in user_info.substring_quotes:
    assert quote in context
    print(f"Verified quote: '{quote}'")

```

- We patch the `openai.OpenAI()` client with `instructor.patch()`. This enables `instructor`'s functionality.
- We define a `context` string that contains the information we want to extract and fact-check against.
- When calling `client.chat.completions.create()`, we pass our `UserInformation` model to `response_model`.
- Crucially, we provide the `context` to the `validation_context` parameter. This is where `CitationMixin` gets the text it needs to verify the `substring_quotes`.
- Finally, we print the extracted `user_info` and iterate through `user_info.substring_quotes` to assert that each quote is indeed present in the original `context`.
