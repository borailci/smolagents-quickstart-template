
# Toon Project Documentation Plan

This plan outlines the process for generating a comprehensive Knowledge Base for the Toon project, enabling tutorial writers to quickly understand the codebase.

We will focus on three key areas:

1.  **Core Package (`packages/toon/src`)**: This is the heart of the Toon project, and its documentation is critical.
2.  **Command-Line Interface (`packages/cli/src`)**: As a primary user entry point, the CLI needs clear documentation.
3.  **Benchmarks (`benchmarks/src`)**: Understanding the benchmarking process is essential for evaluating the project's performance and accuracy.

For each of these areas, we will spawn a dedicated `analyzer-agent` to generate detailed documentation.
