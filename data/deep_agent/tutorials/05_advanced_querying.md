
# Advanced Querying Techniques in RAG-Anything

## 1. Goal

In this tutorial, you will learn how to leverage the advanced querying capabilities of the `RAGAnything` framework. We will explore the differences between `aquery()`, `aquery_with_multimodal()`, and `aquery_vlm_enhanced()`, with practical examples of when and how to use each for both simple and complex querying scenarios.

## 2. Prerequisites

- Python 3.9+
- A working `RAGAnything` instance.
- An understanding of the basic RAG pipeline.

## 3. Architecture

The querying architecture in `RAGAnything` is designed to be flexible and powerful, handling everything from simple text questions to complex multimodal queries. The `QueryMixin` is the heart of this system.

```mermaid
graph TD
    A["User"] -->|Query| B{QueryMixin};
    B --> C{aquery() for text};
    B --> D{aquery_with_multimodal() for multimodal input};
    B --> E{aquery_vlm_enhanced() for context-aware vision};
    C --> F["LLM"];
    D --> F;
    E --> G["Vision Language Model"];
    F --> H["Answer"];
    G --> H;
```

## 4. Step 1: Standard Text Queries with `aquery()`

The most straightforward way to query your knowledge base is with `aquery()`. This method is for text-only questions.

```python
from raganything import RAGAnything

# Assume rag_system is an initialized RAGAnything instance
# await rag_system.process_document_complete("path/to/your/document.pdf")

async def run_text_query(rag_system: RAGAnything):
    answer = await rag_system.aquery("What is the main conclusion of the document?")
    print(answer)
```

*Verification*: You should see a text-based answer generated by the underlying Language Model, based on the content of the document you processed.

## 5. Step 2: Multimodal Queries with `aquery_with_multimodal()`

When you want to ask a question about a specific image or table, `aquery_with_multimodal()` is the tool for the job. You provide the image or table data directly in the query.

### Querying with an Image

```python
from raganything import RAGAnything

async def run_multimodal_image_query(rag_system: RAGAnything):
    answer = await rag_system.aquery_with_multimodal(
        "Describe the content of this image.",
        multimodal_content=[{
            "type": "image",
            "img_path": "path/to/your/image.jpg"
        }]
    )
    print(answer)
```

### Querying with a Table

```python
from raganything import RAGAnything

async def run_multimodal_table_query(rag_system: RAGAnything):
    table_data = "Product,Revenue\nWidget A,1000\nWidget B,2500"
    answer = await rag_system.aquery_with_multimodal(
        "What is the total revenue?",
        multimodal_content=[{
            "type": "table",
            "table_data": table_data
        }]
    )
    print(answer)
```

*Verification*: For the image query, you will get a description of the image. For the table query, you will get an answer based on the provided table data.

## 6. Step 3: VLM-Enhanced Queries with `aquery_vlm_enhanced()`

This is the most advanced querying method. It's useful when your document contains images and the text refers to them (e.g., "as shown in Figure 1"). `aquery_vlm_enhanced()` retrieves the text, finds the referenced image, and uses a Vision Language Model (VLM) to understand the image in the context of the question.

```python
from raganything import RAGAnything

async def run_vlm_enhanced_query(rag_system: RAGAnything):
    # Assumes "my_document.pdf" contains text referring to an image, e.g., "Figure 1 shows..."
    # and `rag_system` has processed this document.
    answer = await rag_system.aquery_vlm_enhanced(
        "What is shown in Figure 1?"
    )
    print(answer)
```

*Verification*: The answer will be a description of the image mentioned in the document, in the context of your question.

## 7. Common Pitfalls

- **`aquery_vlm_enhanced()` without a Vision Model**: This method will fail if `RAGAnything` was not initialized with a `vision_model_func`.
- **Incorrect `multimodal_content` format**: Ensure the `multimodal_content` list contains dictionaries with the correct `type` and data fields (`img_path` or `table_data`).
- **File Paths**: Ensure that the `img_path` provided to `aquery_with_multimodal` is a valid path to an image file.
