# Executive Summary: DeepAgents Project

## Project Overview

The DeepAgents project provides a Python framework for building sophisticated, "deep" AI agents capable of complex, multi-step tasks. It includes a core `deepagents` library for agent creation with features like filesystem access and sub-agent delegation, a `deepagents-cli` for interactive terminal-based use, and a `deepagents-harbor` adapter to integrate with the `harbor` agent evaluation framework.

## Architecture

The architecture is modular:
- The **`deepagents` library** is the foundation, using a middleware-based design on top of LangChain/LangGraph to create agents. Key components reside in `deepagents/middleware`.
- The **`deepagents-cli`** acts as a user-facing application, wrapping the core library to provide an interactive coding assistant. It manages user sessions, state, and can connect to remote "sandboxes" for safe code execution.
- The **`deepagents-harbor` adapter** serves as a bridge to the Harbor evaluation framework. Its `HarborSandbox` translates agent actions into shell commands executed within the secure Harbor environment, enabling performance testing.

## Technologies

- **Language**: Python (3.11+)
- **Framework**: LangChain, LangGraph
- **Key dependencies**: `asyncio`, `harbor` (for evaluation), `tavily-python` (for web search), `langchain-openai`, `rich`, `prompt-toolkit`, and various sandbox client APIs (e.g., `modal`, `runloop-api-client`).

## Learning Path

Recommended order for a new developer to learn this codebase:

1.  **Start with**: The core `deepagents` library. Understand the main entry point (`create_deep_agent`) and the concepts of `AgentMiddleware` and `BackendProtocol`.
2.  **Then understand**: The `deepagents-cli` application in `deepagents_cli/main.py`. See how it uses the core library to build and run an interactive agent, and how it handles local vs. sandbox execution.
3.  **Deep dive into**: The `deepagents-harbor` integration. Analyze `HarborSandbox` to see how agent filesystem actions are translated into secure shell commands for the evaluation environment.
4.  **Practice with**: 
    - Adding a new custom tool to the `deepagents-cli`.
    - Creating a new "Skill" for the CLI agent.
    - Implementing a new shell command within the `HarborSandbox`.

## Glossary

Key terms used across the codebase:

- **AgentMiddleware**: A component that intercepts and modifies an agent's behavior to add features like filesystem access or sub-agent delegation.
- **SubAgent**: A specialized agent invoked by a main agent to perform a specific task, managed by `SubAgentMiddleware`.
- **BackendProtocol**: An interface that defines how an agent interacts with its environment (e.g., filesystem, sandbox), decoupling the agent from the specific implementation.
- **HarborSandbox**: A backend implementation that translates agent actions into shell commands for execution within the secure Harbor evaluation environment.
- **Trajectory**: A structured JSON log that records the entire interaction between the user, agent, and tools, used for performance evaluation.
- **Skill**: A reusable set of instructions (`SKILL.md`) that extends the `deepagents-cli` agent's capabilities for specific tasks.
- **Sandbox**: An isolated remote environment (e.g., Modal, Daytona) for safely executing code generated by the agent, preventing direct access to the local machine.

## Getting Started

Quick pointers for a developer joining tomorrow:

1.  **Set up API Keys**: The agent requires API keys for AI models (`OPENAI_API_KEY`) and tools (`TAVILY_API_KEY`). Store these in a `.env` file.
2.  **Use the CLI**: Start by interacting with the `deepagents-cli`. Experiment with both local mode and a sandbox mode (`--sandbox modal`) to understand the agent's capabilities.
3.  **Review the Prompts**: Check the system prompts and `agent.md` memory files to understand how the agent's behavior is guided.

## Gaps & Risks

- **Missing Documentation**: The current documentation is detailed at the component level, but a higher-level sequence diagram showing a request flow from CLI through the core library to a sandbox would be beneficial.
- **Areas Needing Attention**:
    - **Security**: The use of `--auto-approve` in the `deepagents-cli` is a significant risk and should be used with extreme caution.
    - **Shell Injection**: When modifying the `HarborSandbox`, it is critical to continue the pattern of using `shlex.quote` and Base64 encoding to prevent shell injection vulnerabilities.
