
# Toon Decoding Technical Analysis

## 1. Overview

The Toon decoding modules are responsible for parsing a TOON (Token-Oriented Object Notation) formatted string or stream and converting it into a series of JSON-like events. The package name is `@toon-format/toon`. The process is designed to be efficient and work with both synchronous and asynchronous data sources. The decoding is split into three main stages: scanning, parsing, and decoding, each handled by a dedicated module.

## 2. File-by-File Analysis

### `packages/toon/src/decode/scanner.ts`

- **Purpose**: This file is the first stage of the decoding process. It takes a raw string input (from a stream or an iterable) and converts it into a sequence of `ParsedLine` objects. Each `ParsedLine` object contains the raw line, its indentation level, the line's content without indentation, the calculated depth in the TOON structure, and the line number.
- **Key Components**:
  - `parseLinesSync`: A generator function that processes an `Iterable<string>` and yields `ParsedLine` objects.
  - `parseLinesAsync`: An async generator function that processes an `AsyncIterable<string>` and yields `ParsedLine` objects.
  - `parseLineIncremental`: The core function that processes a single line to calculate indentation and depth, and performs strict mode validation (e.g., checking for tabs or incorrect indentation levels).
  - `StreamingScanState`: An interface that holds the state of the scanning process, including the current line number and a list of blank lines encountered.

### `packages/toon/src/decode/parser.ts`

- **Purpose**: This file provides a set of functions to parse specific syntactic elements of the TOON format from the `ParsedLine` objects generated by the scanner. It is responsible for interpreting the raw string content of a line into more structured information, like array headers, key-value pairs, and primitive values.
- **Key Components**:
  - `parseArrayHeaderLine`: Parses a line that defines an array, extracting its length, delimiter, and optionally the fields for a tabular array.
  - `parseDelimitedValues`: Splits a string into an array of values based on a delimiter, correctly handling quoted strings.
  - `parsePrimitiveToken`: Parses a string token into a JSON primitive (`string`, `number`, `boolean`, `null`).
  - `parseKeyToken`: Extracts the key from a key-value pair, handling both quoted and unquoted keys.

### `packages/toon/src/decode/decoders.ts`

- **Purpose**: This is the central module that orchestrates the decoding process. It uses the scanner to get `ParsedLine` objects and the parser to interpret them. It then generates a stream of `JsonStreamEvent` objects that represent the parsed TOON data. This file contains both synchronous and asynchronous decoders.
- **Key Components**:
  - `decodeStreamSync`: A generator function that takes an `Iterable<string>` and yields `JsonStreamEvent` objects, representing the decoded TOON data in a synchronous manner.
  - `decodeStream`: An async generator function that takes an `AsyncIterable<string>` or `Iterable<string>` and yields `JsonStreamEvent` objects, allowing for asynchronous decoding.
  - `StreamingLineCursor`: A helper class that provides a way to peek, advance, and manage the stream of `ParsedLine` objects.
  - Various `decode*` functions (e.g., `decodeKeyValueSync`, `decodeArrayFromHeaderAsync`) that handle the decoding of specific TOON structures.

## 3. Core Concepts

### Streaming Model

The decoding process is designed around a streaming model, which allows for efficient processing of large TOON documents without having to load the entire document into memory. The process works as a pipeline:

1.  The **scanner** (`scanner.ts`) reads the input source line by line and produces a stream of `ParsedLine` objects.
2.  The **decoder** (`decoders.ts`) consumes the `ParsedLine` objects using the `StreamingLineCursor`.
3.  For each line, the decoder uses the **parser** (`parser.ts`) to understand its content (e.g., if it's a key-value pair, an array header, or a list item).
4.  Based on the parsed information, the decoder yields a series of `JsonStreamEvent` objects (e.g., `startObject`, `key`, `primitive`, `endObject`).

This model is implemented for both synchronous (`Iterable`) and asynchronous (`AsyncIterable`) sources.

### Indentation and Depth

The structure of a TOON document is determined by indentation. The `scanner.ts` module is responsible for calculating the depth of each line based on the number of leading spaces. By default, each level of depth is represented by 2 spaces. The depth is a crucial piece of information used by the decoder to understand the nesting of objects and arrays.

### Data Structures

- **`ParsedLine`**: An interface representing a single line of a TOON document, containing its `raw` content, `indent`, `content` (without indentation), `depth`, and `lineNumber`.
- **`StreamingScanState`**: An object that tracks the state of the scanning process, including the `lineNumber` and information about any `blankLines` encountered.
- **`ArrayHeaderInfo`**: An interface that holds the parsed information from an array header, including its `key` (if any), `length`, `delimiter`, and `fields` (for tabular arrays).
- **`JsonStreamEvent`**: A union of types representing the different events that can be emitted by the decoder, such as `startObject`, `endObject`, `startArray`, `endArray`, `key`, and `primitive`.

## 4. Public API Reference

| Function | Signature | Description |
|---|---|---|
| `decodeStream` | `(source: AsyncIterable<string> | Iterable<string>, options?: DecodeStreamOptions) => AsyncGenerator<JsonStreamEvent>` | Asynchronously decodes a TOON document from a string iterable or async iterable, yielding a stream of `JsonStreamEvent` objects. |
| `decodeStreamSync` | `(source: Iterable<string>, options?: DecodeStreamOptions) => Generator<JsonStreamEvent>` | Synchronously decodes a TOON document from a string iterable, yielding a stream of `JsonStreamEvent` objects. |

### `DecodeStreamOptions`

| Option | Type | Default | Description |
|---|---|---|---|
| `indent` | `number` | `2` | The number of spaces that define a single level of indentation. |
| `strict` | `boolean` | `true` | If `true`, the decoder will throw an error for syntax violations, such as the use of tabs for indentation or incorrect indentation levels. |

## 5. Integration and Usage

To use the TOON decoder, you can import the `decodeStream` or `decodeStreamSync` function from the `@toon-format/toon` package.

### Synchronous Decoding

For synchronous decoding, you can use `decodeStreamSync` with an array of strings or any other iterable.

```typescript
import { decodeStreamSync } from '@toon-format/toon';

const toonData = [
  'name: "John Doe"',
  'age: 42',
];

const events = Array.from(decodeStreamSync(toonData));
// events will be an array of JsonStreamEvent objects
```

### Asynchronous Decoding

For asynchronous decoding from a stream (e.g., a file stream), you can use `decodeStream`.

```typescript
import { decodeStream } from '@toon-format/toon';

async function* createAsyncIterable(data: string[]) {
  for (const line of data) {
    yield line;
  }
}

const toonData = [
  'name: "Jane Doe"',
  'age: 35',
];

const stream = createAsyncIterable(toonData);

for await (const event of decodeStream(stream)) {
  // process each JsonStreamEvent
}
```
